# Security policy

Pathquill is a bounded Linux MVP. Its tested scope and recovery limitations are
recorded in docs/CLOSEOUT.md; it has no production-support or response-time SLA.

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting at https://github.com/andrew29mo/pathquill/security/advisories/new.
Include the revision, reproduction steps and expected/observed behavior.
Use synthetic or redacted examples. Raw stores, archive receipts and local
administrative status contain private network data; keep them out of public
issues and pull requests.

The current main branch is the maintained development line. Repository secret
scanning and push protection are enabled, but do not establish complete
anonymity or prove arbitrary uploaded artifacts contain no sensitive data.
